# مشروع الأمان الوطني — عرض تقديمي تفاعلي (موقع)

موقع ثابت (static) بلا أي اعتماديات: `index.html` + مجلد `assets/`.

## النشر على Vercel (دقيقتان)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي (index.html و assets/ و README.md).
2. في Vercel: **Add New → Project → Import** المستودع.
3. Framework Preset: **Other**. اترك Build Command و Output Directory فارغين. اضغط **Deploy**.
4. الرابط الناتج جاهز للإرسال.

## الاستخدام أثناء العرض
- زر **ابدأ العرض مع التعليق الصوتي** يشغّل الصوت والتقدم التلقائي (المتصفح يمنع تشغيل الصوت قبل نقرة واحدة).
- الأسهم ← → أو مسافة للتنقل، **M** لكتم/تشغيل الصوت، زر ملء الشاشة أسفل اليسار.
- على الهاتف: مرّر للأعلى/الأسفل.
- لتبديل التعليق الصوتي لاحقاً: استبدل ملفات `assets/audio/slideN.mp3` بنفس الأسماء.
